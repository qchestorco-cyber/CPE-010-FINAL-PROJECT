# CPE-010-FINAL-PROJECT
Emulation of route finding[cite: 3].

## Overview
This project simulates a route-finding system. It prompts the user for a location, verifies its existence using a hash map, and then calculates routes based on user preference[cite: 1, 3]:
* **All Paths:** Traverses the graph using Depth-First Search (DFS) and sorts the paths using Quick Sort[cite: 1].
* **Optimal Path:** Calculates and displays the most efficient route using Dijkstra's Algorithm[cite: 1].

## Project Files
* `main.cpp` - Main program execution[cite: 3].
* `graph.h` - Graph data structure and traversal logic[cite: 3].

* `interface.h` - User interface and console outputs[cite: 3].
* `routes.h` - Pathfinding algorithms and route management[cite: 3].
